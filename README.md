Program Aplikasi Prediksi Prodi Pilihan dibuat menggunakan bahasa pemrograman Python dengan library Tkinter untuk membuat GUI (Graphical User Interface) atau antarmuka grafis. Pada bagian awal, import tkinter as tk dan from tkinter import ttk digunakan untuk mengimpor komponen GUI. Kemudian, tk.Tk() digunakan untuk membuat jendela utama, title() untuk memberikan judul aplikasi, geometry() untuk mengatur ukuran jendela, dan configure() untuk mengatur warna latar belakang. Program menggunakan Label untuk menampilkan judul aplikasi, Frame sebagai wadah komponen, serta Entry untuk membuat kolom input nilai. Daftar 10 mata pelajaran disimpan dalam sebuah list bernama mata_pelajaran, kemudian perulangan for dan enumerate() digunakan untuk membuat label mata pelajaran dan kolom input secara otomatis. Metode grid() mengatur posisi input dalam dua kolom agar tampilan lebih rapi, sedangkan append() menyimpan setiap kolom input ke dalam list input_nilai.

Selanjutnya, program membuat fungsi hasil_prediksi() yang bertugas menampilkan hasil prediksi ketika tombol ditekan. Perintah label_hasil.config() digunakan untuk mengubah teks hasil menjadi Hasil Prediksi: Teknologi Informasi dan mengubah warna tulisan menjadi hijau. Tombol dibuat menggunakan ttk.Button() dengan tulisan Hasil Prediksi dan parameter command=hasil_prediksi agar fungsi dijalankan ketika tombol ditekan. Program juga menggunakan Frame dan Label untuk menampilkan hasil prediksi di bagian bawah aplikasi, dengan teks awal Hasil prediksi akan muncul di sini. Hasilnya akan berubah setelah tombol ditekan. Prediksi selalu menghasilkan program studi Teknologi Informasi karena program tidak melakukan perhitungan berdasarkan nilai yang dimasukkan. Terakhir, root.mainloop() digunakan untuk menjalankan aplikasi dan menjaga jendela tetap aktif selama pengguna berinteraksi dengan program.
